## Sobre o projeto

O **RotaPB** é um site desenvolvido como parte do Projeto Integrador do curso de Análise e Desenvolvimento de Sistemas (ADS) do UNIPÊ.

Nosso objetivo é apresentar a Paraíba de uma forma simples e interativa, valorizando seus pontos turísticos, sua cultura, culinária, história e curiosidades, do Sertão ao Litoral.

## Objetivo

Criar uma plataforma que ajude os visitantes a conhecer melhor a Paraíba, explorar destinos turísticos e descobrir as riquezas do nosso estado.

## Tecnologias utilizadas

- HTML5 — Estrutura das páginas
- CSS3 — Estilização e layout
- JavaScript — Interatividade
- Bootstrap — Responsividade e componentes visuais

## Funcionalidades iniciais

- Página inicial com apresentação do projeto
- Menu de navegação
- Destinos turísticos em destaque
- Informações sobre a cultura e a culinária paraibana
- Galeria de imagens
- Formulário de busca de roteiros
