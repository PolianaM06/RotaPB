# RotaPB

**Você conhece a Paraíba?** Site de uma agência de turismo fictícia que apresenta a Paraíba de dentro pra fora, do Sertão ao Litoral. Projeto Integrador de Desenvolvimento Front-End para Web · UNIPÊ.

## Estrutura
```
paraiba-adentro/
├── index.html            Início (Pessoa 1)
├── pages/
│   ├── conhece.html      Você conhece? — abas do mapa + cartas (Pessoa 2)
│   ├── culinaria.html    Comidas típicas, caranguejo, drinks, restaurantes (Pessoa 2)
│   ├── cultura.html      Artes plásticas, grandes nomes da música, a cena hoje (TODO: dono)
│   ├── roteiros.html     Filtro + monte sua rota (Pessoa 3)
│   ├── contato.html      Formulário + mapa (Pessoa 3)
│   ├── desafio.html      Desafio: escape room por regiões + certificado
│   └── creditos.html     Créditos das fotos, fontes e tecnologias
├── css/style.css
├── js/script.js          Todas as funcionalidades (comentadas em português)
├── images/               mapa-paraiba.svg (o carneiro), bandeira-paraiba.svg
├── assets/               Bootstrap e Bootstrap Icons (cópia local)
└── docs/requisitos.md    Checklist de todas as etapas
```

## Como rodar
Abra a pasta no VS Code e use a extensão **Live Server** no `index.html`.

## Funcionalidades em JavaScript
Acessibilidade (modo noturno, tamanho do texto, alto contraste), voltar ao topo, abas do mapa, cartas que viram, filtros (Culinária e Roteiros), monte sua rota, player do Spotify, máscara de telefone, validação do formulário, newsletter, **Desafio** (escape room com 4 salas e certificado) e **Passaporte** (8 carimbos salvos no navegador).

## Como trabalhar
1. Procure por `TODO` (Ctrl+Shift+F no VS Code): é o texto que falta preencher.
2. Um commit por tarefa, cada um com a própria conta do GitHub.

## Tecnologias
HTML5 semântico · CSS3 · JavaScript · Bootstrap 5.3 · Bootstrap Icons · Git/GitHub
